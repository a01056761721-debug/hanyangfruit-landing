# 한양과일 사이트 운영 가이드

사장님이 직접 자주 바꾸시는 것들 (상품, 후기 사진, 영상 등) 을 어떻게 수정/추가하는지 정리한 문서입니다.

> **추천 작업 방식**: 깃허브(github.com) 웹사이트에서 직접 수정 → 커밋 → 1~2분 후 사이트에 자동 반영.
> 컴퓨터에 따로 프로그램 설치 안 하셔도 됩니다.

---

## 한 줄 요약

| 바꾸고 싶은 것 | 어디서 |
|---|---|
| 상품 (이름/가격 등) | `src/data/products.json` 편집 |
| 상품 사진 | `public/products/` 폴더에 파일 업로드 |
| 후기 사진 추가/삭제 | `public/reviews/` 폴더 파일 업로드/삭제 |
| 히어로 영상 / 대표 사진 / 소개 영상 | `src/data/site.json` 편집 또는 같은 이름으로 파일 덮어쓰기 |
| 주문방법 4단계 사진 | `public/order/` 폴더에서 같은 이름으로 덮어쓰기 |
| 공감 카드 사진 (비싼데 맛없는 과일 등) | `public/empathy/` 폴더에서 같은 이름으로 덮어쓰기 |

수정한 뒤에는 사이트가 자동으로 새로 만들어집니다 (Vercel을 쓰고 있다면 깃허브에 푸시하면 자동 배포).

---

## 1. 후기 사진 추가/삭제

### 추가하기

1. 사장님이 자랑하고 싶은 후기 사진을 준비합니다 (PNG, JPG, WEBP 모두 가능)
2. `public/reviews/` 폴더에 사진 파일을 그냥 넣습니다.
3. 끝. 사이트가 다음에 만들어질 때 자동으로 후기 슬라이드에 추가됩니다.

### 순서

- 파일명 순서대로 정렬됩니다.
- 예시: `review-01.png`, `review-02.png`, … 처럼 번호를 붙이시면 그 순서대로 보입니다.
- 한글 파일명도 가능합니다. 예: `2026-05-19-카톡캡쳐.png`
- 순서를 바꾸고 싶으면 파일명을 바꾸시면 됩니다.

### 삭제하기

- 해당 사진 파일을 `public/reviews/` 폴더에서 그냥 지우시면 됩니다.

### 확인하기

- 로컬에서 미리 확인하고 싶으면 `npm run dev` 를 실행한 뒤 사이트를 열어 보시면 됩니다.

## 2. 상품 추가 / 수정 / 삭제

상품 정보는 모두 `src/data/products.json` 한 파일에 있습니다. 이 파일만 고치면 사이트에 반영됩니다.

### 파일 구조

```json
{
  "categories": [
    {
      "name": "과일",
      "description": "매일 새벽 직접 맛보고 고른 과일만 골라 소개해드려요",
      "products": [
        {
          "title": "[당일선별] 한입에 톡 터지는 방울토마토",
          "imageSrc": "/products/fruit-01.png",
          "imageAlt": "손바닥 위 방울토마토",
          "soldCount": "218,991",
          "originalPrice": "29,900원",
          "discountRate": "53%",
          "price": "13,900원",
          "rating": "4.8",
          "reviewCount": "8,079"
        }
      ]
    }
  ]
}
```

### 각 항목 설명

| 필드             | 설명                                            | 예시                        |
| ---------------- | ----------------------------------------------- | --------------------------- |
| `title`          | 상품 이름                                       | `"[당일선별] 방울토마토"` |
| `imageSrc`       | 상품 사진 경로 (또는 외부 이미지 URL)            | `"/products/fruit-01.png"` |
| `imageAlt`       | 사진을 못 봤을 때 보일 설명 (검색엔진용)         | `"손바닥 위 방울토마토"`    |
| `soldCount`      | 구매한 사람 수 (`개 구매중` 옆에 표시됨)        | `"218,991"`                 |
| `originalPrice`  | 원래 가격                                       | `"29,900원"`                |
| `discountRate`   | 할인율                                          | `"53%"`                     |
| `price`          | 판매가                                          | `"13,900원"`                |
| `rating`         | 별점 (별 1개 옆에 표시됨)                       | `"4.8"`                     |
| `reviewCount`    | 후기 개수                                       | `"8,079"`                   |

> 카테고리 번호 (01, 02, …) 는 사이트가 자동으로 매기므로 직접 안 적으셔도 됩니다.

### 상품 하나 추가하기

1. 추가하고 싶은 카테고리의 `products` 배열에 새 상품 정보(중괄호 `{}` 한 덩어리)를 추가합니다.
2. 콤마(`,`)로 항목들 사이를 구분해야 합니다. **마지막 항목 뒤에는 콤마가 없어야 합니다.**
3. 상품 사진 파일을 `public/products/` 폴더에 넣고 그 파일명을 `imageSrc`에 적으세요.

### 상품 수정하기

해당 항목의 글자만 바꾸시면 됩니다. 큰따옴표(`"`)는 유지해야 합니다.

```json
"price": "12,900원"   ← 가격만 바꿈
```

### 상품 삭제하기

해당 중괄호 `{}` 한 덩어리를 통째로 지우시면 됩니다. 주변 콤마 위치를 확인하세요.

### 카테고리 추가하기

`categories` 배열에 새 카테고리 한 덩어리를 추가합니다.

```json
{
  "name": "수산",
  "description": "산지직송 신선한 수산물",
  "products": [
    { ... 상품 정보 ... }
  ]
}
```

### 카테고리 삭제하기

해당 카테고리 한 덩어리 (중괄호 `{}` 안의 모든 것) 를 지우시면 됩니다.

## 3. 상품 사진 올리기

1. 사진 파일을 준비합니다 (정사각형 권장, 1000×1000 정도면 충분).
2. `public/products/` 폴더에 사진 파일을 넣습니다.
3. `products.json` 에서 해당 상품의 `imageSrc` 에 그 파일명을 넣습니다.

```json
"imageSrc": "/products/내가올린사진.png"
```

> 경로는 항상 `/products/` 로 시작합니다 (앞에 슬래시 꼭 넣어주세요).

## 4. 영상 / 대표 사진 교체

### 4-1. 깃허브 웹사이트에서 같은 이름으로 덮어쓰기 (가장 쉬움)

영상이나 사진을 바꾸고 싶을 때 **가장 쉬운 방법**입니다.

1. 깃허브에서 해당 폴더로 이동 (예: `public/videos/`)
2. 바꿀 파일 클릭 (예: `hero-bg-v2.mp4`)
3. 우측 상단 **... → "Delete file"** 클릭 → Commit
4. 다시 그 폴더에서 **"Add file" → "Upload files"** 클릭
5. 새 영상을 **반드시 같은 이름**(`hero-bg-v2.mp4`)으로 업로드
6. Commit → 1~2분 후 사이트 반영

> 같은 이름으로 올리면 사이트 코드를 안 바꿔도 자동 적용됩니다.

### 4-2. 새 파일명을 쓰고 싶을 때

옛날 영상을 백업으로 남기고 싶으면 `src/data/site.json`을 편집하시면 됩니다.

```json
{
  "media": {
    "heroVideo": "/videos/hero-bg-v2.mp4",
    "differenceVideo": "/videos/hanyang-difference.mp4",
    "founderImage": "/people/hanyang-owner-v2.png"
  }
}
```

| 항목 | 어디에 쓰이는 영상/사진 |
|---|---|
| `heroVideo` | 메인 첫 화면 배경 영상 |
| `differenceVideo` | "뭐가 다를까요?" 섹션 영상 |
| `founderImage` | 페이지 하단 말풍선 옆 대표 사진 |

#### 새 영상으로 바꾸는 순서
1. `public/videos/` 폴더에 새 영상 업로드 (예: `hero-spring.mp4`)
2. `src/data/site.json` 열어서 `heroVideo` 의 값을 `"/videos/hero-spring.mp4"` 로 수정
3. Commit → 사이트 반영

## 5. 주문방법 4단계 사진 / 공감 카드 사진 바꾸기

이 사진들은 코드 안에 4장/6장으로 정해진 갯수로 들어가 있어서, **같은 이름으로 덮어쓰는 게 가장 쉽습니다**.

### 주문방법 사진 (4장)
- 위치: `public/order/`
- 파일명:
  - `order-flow-01.png` (01. 오픈채팅 입장)
  - `order-flow-02.png` (02. 오늘 들어온 과일 확인)
  - `order-flow-03.png` (03. 주문)
  - `order-flow-04-delivery-door.png` (04. 당일 배송)

### 공감 카드 사진 (3카드 × 2장씩, 총 6장)
- 위치: `public/empathy/`
- 파일명:
  - 비싼데 맛없는 과일: `pain-1-a.png`, `pain-1-b.png`
  - 겉은 괜찮아 보여도 속 상태가 별로인 과일: `pain-2-a.png`, `pain-2-b.png`
  - 제대로 검수하지 않은 과일: `pain-3-a.png`, `pain-3-b.png`

> 사진을 더 추가하거나 텍스트도 같이 바꾸고 싶으시면 저(AI)에게 부탁하시면 코드까지 같이 수정해 드립니다.

## 6. 사이트 반영 (배포)

수정한 파일을 깃허브에 푸시하면 Vercel이 자동으로 새 사이트를 만듭니다 (대략 1~2분 소요).

```
git add .
git commit -m "상품 업데이트"
git push
```

## 7. 자주 하는 실수 (꼭 확인!)

- **JSON 파일에서 콤마 위치**: 마지막 항목 뒤에는 콤마(`,`)가 없어야 합니다.
  ```json
  "price": "12,900원",
  "rating": "4.8"   ← 마지막이라 콤마 없음
  ```
- **큰따옴표 유지**: 글자는 항상 큰따옴표(`"`)로 감싸야 합니다.
- **파일 저장 후 깃허브에 올리기**: 저장만 하면 사장님 컴퓨터에만 바뀌어 있는 상태입니다. 푸시해야 사이트가 바뀝니다.
- **사진 파일명에 한글/공백 자제**: 가능하면 영문+숫자+하이픈으로 (예: `apple-01.png`).
